# 东华业务报表系统

## 项目概述

东华业务报表系统是一个基于 Flask 的 Web 应用程序，用于查询和管理医院业务数据，包括住院工作量、门诊查询等功能。

**版本**: 1.0.1  
**技术栈**: Python + Flask + pyodbc + SQL Server + Bootstrap

## 功能模块

### 1. 用户管理

| 功能 | 说明 |
|------|------|
| 用户注册 | 注册新用户（员工编号、姓名、密码） |
| 用户登录 | 用户名+密码登录 |
| 用户列表 | 查看所有用户 |
| 编辑用户 | 修改用户信息、钉钉ID |
| 删除用户 | 删除用户账户 |

### 2. 住院工作量查询

支持四种查询类型：

| 类型 | 存储过程 | 说明 |
|------|---------|------|
| 主任医师 | Search_Doctor_SP_Workload | 正高职称医师工作量 |
| 副主任医师 | Search_Doctor_AP_Workload | 副高职称医师工作量 |
| 护士 | Search_Nurse_Workload | 护士工作量 |
| 麻醉师 | Search_Anes_Workload | 麻醉师工作量 |

**查询参数**：
- 姓名
- 日期范围（开始日期、结束日期）

### 3. 门诊查询

- 按医生姓名查询门诊数据
- 从 Excel 文件读取历史数据
- 支持多年度数据汇总
- 员工编号记录到历史表

### 4. 历史记录

- 查询历史自动保存
- 支持导出为 Excel
- 支持按记录删除
- 记录内容包括：员工编号、姓名、查询类型、日期范围、导出文件

### 5. 钉钉推送

- 将查询结果发送到钉钉群
- 支持 PDF 文件发送

### 6. 配置管理

- 数据库连接配置
- 输出目录配置
- 门诊报表目录配置

## 运行方式

### 方式一：直接运行

```bash
cd d:/codebuddy/业务报表
python web_app_inpatient.py
```

### 方式二：打包运行

```bash
cd d:/codebuddy/业务报表
pyinstaller 东华住院工作量查询.spec
# 运行 dist/东华住院工作量查询.exe
```

### 方式三：MCP 服务（可选）

系统同时提供 MCP（Model Context Protocol）入口，供 DSH、Claude Desktop 等客户端调用查询能力：

```bash
pip install -r requirements-mcp.txt
python mcp_server.py --status      # 检查配置与数据库连通性
python mcp_server.py               # 以 stdio 方式启动 MCP 服务
```

提供 `query_inpatient_workload`、`query_outpatient_workload`、`query_patients`、
`generate_workload_report`、`database_status` 五个工具，与 Web 端共用同一套查询逻辑和配置。
详见 [MCP.md](MCP.md)。

## 配置文件说明

配置文件位于应用目录下的 `config.ini`，包含以下配置段：

### [database] - 数据库配置
- `server`: SQL Server 服务器地址
- `port`: 端口号
- `user`: 数据库用户名
- `password`: 数据库密码
- `database`: 数据库名

### [paths] - 路径配置
- `output_dir`: 主输出目录
- `xls_dir`: Excel 文件输出目录
- `pdf_dir`: PDF 文件输出目录
- `clinic_data_dir`: 门诊数据目录

### [clinic] - 门诊配置
- `clinic_reports`: 门诊报表文件列表
