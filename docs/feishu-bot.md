# 飞书机器人：消息查询

用户在飞书里给机器人发一句话，机器人回查询结果（或 Excel/PDF 报表）。
走飞书「长连接」模式，**不需要公网地址**，适合医院内网部署。

- 入口：`feishu_bot.py`（仓库根目录）
- 依赖：`pip install -r requirements-bot.txt`（`lark-oapi`）
- 凭证：`config.json` 的 `feishu` 段（与文件推送共用）

## 1. 开发者后台需要开启的配置

| 项目 | 值 |
|------|----|
| 订阅方式 | 长连接 |
| 事件 | `im.message.receive_v1`（接收消息 v2.0） |
| 权限 | `im:message.p2p_msg:readonly`（单聊）、`im:message.group_at_msg:readonly`（群聊 @机器人）、`im:message:send_as_bot`（发消息） |
| 机器人能力 | 已开启 |

> 只发文件不接收消息的话，`im:message:send_as_bot` 就够了；接收消息必须额外订阅事件并开通读消息权限。

## 2. 启动

```powershell
python feishu_bot.py
```

启动后常驻，收到消息立即处理。可和 Flask 服务同时运行，二者互不影响。

## 3. 指令

单聊直接发，群里先 @机器人。日期缺省为「本月 1 日 ~ 今天」。

| 指令 | 说明 |
|------|------|
| `门诊 01478 席林 2024-01-01 2026-10-18` | 门诊工作量（员工编号必填） |
| `住院 席林 副主任 2026-01-01 2026-06-30` | 住院工作量，职称可用 主任/副主任/护士/麻醉 |
| `患者 席林 2026-06-01 2026-06-30` | 患者明细（按医生） |
| `患者 科室 针灸科 2026-01-01 2026-10-18` | 按科室 / 按诊断（`诊断 颈椎病`）/ 按护士（`护士 张三`） |
| `帮助` | 使用说明 |

命令末尾加「文件」「导出」或「报表」，改为回复 Excel/PDF 文件。

## 4. 回复示例

```
【门诊工作量】席林（工号 01478）
统计期间：2024-01-01 ~ 2026-10-18
2024 年：5 人次
2025 年：2235 人次
2026 年：2484 人次
合计：4724 人次
```

患者明细默认只回前 10 条并提示总数，需要全量就加「文件」。

## 5. 权限控制

`config.json` 里 `feishu.allowed_open_ids` 为空表示租户内所有人都能用；
填入 open_id 列表后，只有列表内的人可以使用（适合只给科室管理员开）。

```json
"feishu": {
  "allowed_open_ids": ["ou_ff452b1e1056e6415807238fbc03f075"]
}
```

## 6. 排障

| 现象 | 处理 |
|------|------|
| 发了消息没反应 | 后台没订阅 `im.message.receive_v1`，或订阅方式不是长连接 |
| 回复「你没有使用权限」 | `allowed_open_ids` 里有值但当前用户不在列表 |
| 启动即报 `未配置飞书 app_id / app_secret` | `dist/config.json` 缺 `feishu` 段 |
| 长连接反复重连 | 检查机器到 `open.feishu.cn` 的网络；该域名通常不需要代理 |
